# StickAI

Copy of the Lovable project "StickAI" (TanStack Start + React 19 + Tailwind 4 + zustand).

## Run it
```bash
npm install
npm run dev
```
Needs Node.js 20+ (or Bun). Open the URL it prints.

## What the app does now
- **Chat** with your StickAI models (`stick`, `stick-1`, `stick-1-1`, `stick-2`, `stick-2-1`, `stick-build`) through `/api/chat`.
  If `STICK_API_URL` isn't set, local development falls back to a simulated "preview" reply; production shows an error instead.
- **Plugins** page with 22 plugins. **Gmail, Google Calendar, Google Drive and Slack are real** (OAuth + tool calls).
  The other 18 are preview-only until you add server code for them.
- **Sign-in screen:** people must sign in or create an account before they can chat. The server enforces it, so chat and images can't be used without an account. Limits: 60 messages and 20 images per person per hour, 10 sign-in tries per email per 15 minutes. Set `STICK_ALLOW_GUESTS=true` to turn the requirement off for local testing.
- **Continue with Google / Apple:** buttons appear on the sign-in screen when the server has the keys (see `.env.example`). Google needs the extra redirect URL `{APP_URL}/api/auth/google/callback`. Apple needs a paid Apple Developer account and an https address (no localhost). Accounts are matched by verified email, so signing in with Google after creating a password account with the same email opens the same account.
- **Accounts + cloud sync** (email/password). Chats and projects sync as text; attached images stay on the device.
- **Projects**, **Scheduled** tasks (run while the app is open in a tab), **Library**, **Images**, **More**.

## Setup
1. `cp .env.example .env` and fill it in (see comments in the file), then `npm install && npm run dev:env`.
2. **Model:** set `STICK_API_URL` (+ `STICK_API_KEY`). The server calls `POST {STICK_API_URL}/chat/completions` (OpenAI format, streaming, tool calls).
3. **Saving data:** create a free Upstash Redis database and set the two `UPSTASH_*` variables. Without them everything lives in server memory.
4. **Google plugins:** in Google Cloud Console create an OAuth client (type "Web application"), enable the Gmail, Calendar and Drive APIs, and add the redirect URL
   `{APP_URL}/api/oauth/google/callback`. Put the client id/secret in `.env`.
5. **Slack:** create a Slack app, add the user scopes `search:read`, `chat:write`, `channels:read`, and the redirect URL `{APP_URL}/api/oauth/slack/callback`.
6. Set `SESSION_SECRET` to a long random string before deploying.

**Images with Gemini:** set `STICK_IMAGE_PROVIDER=gemini`, `GEMINI_API_KEY`, and `STICK_IMAGE_MODEL` (e.g. `gemini-3.1-flash-image-preview`; confirm the current name in Google AI Studio). Any other image provider that offers an OpenAI-style `/images/generations` endpoint works with `STICK_IMAGE_URL`.

## Showing up on Google as "StickAI / Made by Stick"
The page title is **StickAI** and the description starts with **Made by Stick**; structured data names the company **Stick**. To make it work:
1. Deploy the app to a real public address and set `VITE_SITE_URL` to it **before building**.
2. Add the site in Google Search Console (search.google.com/search-console), verify it (put the code in `VITE_GOOGLE_SITE_VERIFICATION`), and submit `/sitemap.xml`.
3. Wait. Google decides what it shows and when; new sites can take days to weeks to appear. Edit the wording in `src/lib/site.ts`.

## Known limits
- No "forgot password" or email check yet (both need an email-sending service such as Resend). Until then a forgotten password can't be recovered.
- Google may show an "unverified app" warning until your OAuth app is verified (fine for yourself and test users).
- Scheduled tasks only run while StickAI is open. Running them when it's closed needs a server cron job.
- Cloud sync is last-write-wins per chat; it does not sync scheduled tasks, settings or images.
- Adding another real plugin: add an executor in `src/server/tools.ts` and a provider entry in `src/server/providers.ts`.
